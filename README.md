Description :
This repository contains my Week 3 assignment for the TurtleSim Mastery task in the ROS2 course.  
It demonstrates the implementation of (Computer Vision Pipeline) and (Navigation System), where multiple nodes work together for image processing and autonomous navigation.

• Computer Vision Pipeline Implementation : 

The computer vision part includes several nodes responsible for image capture, processing, and feature extraction.

Nodes :

• Node 1 : (Camera Driver) – Captures raw images from the webcam.  
• Node 2 : (Image Filter) – Applies image processing operations (e.g., grayscale, blurring).  
• Node 3 : (Feature Extraction) – Detects and highlights key features from the image.  
• Node 4 : (Object Detection) – Identifies objects or specific patterns in the frame.  

• Navigation System Implementation :

The navigation system allows the robot to move intelligently by planning and following a path.

Nodes :

• Node 1 : (Path Planning) – Generates movement paths for the robot to follow.  
• Node 2 : (Motor Driver) – Executes the planned movement commands on the simulated robot.
